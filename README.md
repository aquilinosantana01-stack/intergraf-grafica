# Ejercicios Propuestos - Windows Forms en C#

## Descripción

Este repositorio contiene los ejercicios desarrollados en **C#** utilizando **Windows Forms** en Microsoft Visual Studio. Cada ejercicio fue realizado con el objetivo de practicar el uso de controles gráficos, el manejo de eventos y la interacción con el usuario mediante interfaces de escritorio.

---

## Ejercicio 1 - Conversor de Unidades

### Descripción
Aplicación que permite convertir unidades utilizando un **ComboBox** para seleccionar el tipo de conversión (Kilómetros ↔ Millas o Celsius ↔ Fahrenheit). El usuario introduce el valor en un **TextBox** y el resultado se muestra en un **Label**.

### Controles utilizados
- Label
- TextBox
- ComboBox
- Button

---

## Ejercicio 2 - Control de Asistencia

### Descripción
Aplicación para registrar la asistencia de estudiantes. El usuario selecciona un estudiante desde un **ListBox**, marca su asistencia mediante un **CheckBox** y el sistema genera un resumen de los estudiantes presentes.

### Controles utilizados
- ListBox
- CheckBox
- Button
- Label

---

## Ejercicio 3 - Menú del Colmado

### Descripción
Aplicación que simula un sistema de ventas de un colmado. El usuario selecciona un producto desde un **ComboBox**, introduce la cantidad en un **TextBox** y elige la forma de pago mediante **RadioButton**. El sistema calcula automáticamente el total de la compra y lo muestra en un **Label**.

### Controles utilizados
- ComboBox
- TextBox
- RadioButton
- Button
- Label

---

## Ejercicio 4 - Registro de Clientes

### Descripción
Aplicación para registrar clientes mediante un formulario. Se validan los campos de nombre, teléfono y correo electrónico antes de agregar el cliente a un **ListBox**, donde se muestran todos los registros realizados.

### Controles utilizados
- Label
- TextBox
- ListBox
- Button

---

## Tecnologías utilizadas

- **Lenguaje de programación:** C#
- **Framework:** .NET Windows Forms
- **Entorno de desarrollo:** Microsoft Visual Studio Community

---

## Objetivo

Fortalecer los conocimientos sobre el desarrollo de aplicaciones de escritorio utilizando Windows Forms, implementando controles gráficos, validación de datos y programación orientada a eventos.
