# Ejercicios Guiados de Windows Forms en C#

## Descripción

Este proyecto contiene cuatro ejercicios desarrollados en C# utilizando Windows Forms en Microsoft Visual Studio. Cada ejercicio tiene como objetivo poner en práctica el uso de los controles gráficos, la programación orientada a eventos y la interacción con el usuario mediante una interfaz visual.

---

## Ejercicio 1 - Calculadora Básica

### Descripción
Aplicación que permite realizar operaciones matemáticas básicas entre dos números ingresados por el usuario.

### Funcionalidades
- Ingresar dos números.
- Realizar suma.
- Realizar resta.
- Realizar multiplicación.
- Realizar división.
- Mostrar el resultado en pantalla.

### Controles utilizados
- Label
- TextBox
- Button

---

## Ejercicio 2 - Registro de Datos

### Descripción
Aplicación diseñada para capturar información ingresada por el usuario y mostrarla posteriormente en la interfaz.

### Funcionalidades
- Capturar datos del usuario.
- Mostrar la información ingresada.
- Validar que los campos requeridos estén completos.

### Controles utilizados
- Label
- TextBox
- Button

---

## Ejercicio 3 - Menú del Colmado

### Descripción
Aplicación que simula un pequeño sistema de ventas de un colmado. El usuario selecciona un producto, introduce la cantidad deseada y elige la forma de pago. El programa calcula automáticamente el total de la compra.

### Funcionalidades
- Seleccionar un producto desde un ComboBox.
- Introducir la cantidad de productos.
- Seleccionar la forma de pago.
- Calcular el total de la compra.
- Mostrar el monto final junto con el método de pago seleccionado.

### Controles utilizados
- ComboBox
- TextBox
- RadioButton
- Button
- Label

---

## Ejercicio 4 - Integración de Controles

### Descripción
Aplicación que integra diferentes controles de Windows Forms para reforzar el manejo de eventos, el procesamiento de información y la interacción con el usuario.

### Funcionalidades
- Capturar información mediante controles gráficos.
- Validar los datos ingresados.
- Procesar la información.
- Mostrar los resultados obtenidos en la interfaz.

### Controles utilizados
- Label
- TextBox
- Button
- ComboBox
- RadioButton

---

## Tecnologías utilizadas

- Lenguaje de programación: C#
- Plataforma: .NET Windows Forms
- Entorno de desarrollo: Microsoft Visual Studio Community

---

## Objetivo del proyecto

Desarrollar aplicaciones de escritorio utilizando Windows Forms para fortalecer los conocimientos sobre el uso de controles gráficos, programación orientada a eventos, validación de datos y creación de interfaces gráficas amigables para el usuario.
