# Ejercicios Guiados de Windows Forms en C#

## Descripción

Este proyecto reúne cuatro ejercicios desarrollados en C# utilizando Windows Forms en Microsoft Visual Studio. El propósito de estos ejercicios es practicar el uso de controles gráficos, el manejo de eventos y la creación de interfaces de usuario para aplicaciones de escritorio.

---

## Ejercicio 1 - Conversor de Temperatura

### Descripción
Aplicación que permite convertir temperaturas entre grados Celsius y grados Fahrenheit de forma rápida y sencilla.

### Funcionalidades
- Ingresar una temperatura en grados Celsius.
- Convertir de Celsius a Fahrenheit.
- Convertir de Fahrenheit a Celsius.
- Mostrar el resultado de la conversión.

### Controles utilizados
- Label
- TextBox
- Button

---

## Ejercicio 2 - Registro de Datos

### Descripción
Aplicación que permite capturar información ingresada por el usuario y mostrarla en la interfaz.

### Funcionalidades
- Capturar datos del usuario.
- Mostrar la información ingresada.
- Validar que los campos requeridos estén completos.

### Controles utilizados
- Label
- TextBox
- Button

---

## Ejercicio 3 - Menú del Colmado

### Descripción
Aplicación que simula un sistema de ventas de un colmado. El usuario selecciona un producto, introduce la cantidad que desea comprar y elige el método de pago. El sistema calcula automáticamente el total de la compra y lo muestra en pantalla.

### Funcionalidades
- Seleccionar un producto desde un ComboBox.
- Introducir la cantidad de productos.
- Elegir la forma de pago (Efectivo o Tarjeta).
- Calcular el total de la compra.
- Mostrar el monto final junto con la forma de pago seleccionada.

### Controles utilizados
- ComboBox
- TextBox
- RadioButton
- Button
- Label

---

## Ejercicio 4 - Integración de Controles

### Descripción
Aplicación que integra diferentes controles de Windows Forms para fortalecer el manejo de eventos, la validación de datos y la interacción con el usuario.

### Funcionalidades
- Capturar información mediante controles gráficos.
- Procesar los datos ingresados.
- Mostrar los resultados en la interfaz.
- Validar la información antes de ejecutar las operaciones.

### Controles utilizados
- Label
- TextBox
- ComboBox
- RadioButton
- Button

---

## Tecnologías utilizadas

- Lenguaje de programación: C#
- Framework: .NET Windows Forms
- Entorno de desarrollo: Microsoft Visual Studio Community

---

## Objetivo

Desarrollar aplicaciones de escritorio utilizando Windows Forms para fortalecer los conocimientos sobre el uso de controles gráficos, programación orientada a eventos y creación de interfaces amigables para el usuario.
